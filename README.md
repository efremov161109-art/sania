# BlueDriver Launcher — версия 1.1

Исходный Android-проект лаунчера для автомобильной магнитолы с Android 9 (API 28).

## Что уже заложено

- Русский интерфейс.
- Тёмно-синий автомобильный стиль с фиолетовыми акцентами.
- Большое окно навигации и отдельная компактная карточка музыки.
- Кнопки радио и установленных приложений.
- Встроенный экран голосового помощника.
- Приветствие «Слушаю, мой господин».
- Подключён офлайн-движок распознавания речи Vosk.
- Базовые голосовые команды: открыть навигацию, музыку, радио, список приложений.

## Важно про голосовой помощник

Голосовой помощник не вызывает Google Assistant и не требует установленного голосового сервиса магнитолы. Распознавание задумано через Vosk прямо внутри приложения.

**Для офлайн-распознавания обязательно добавьте русскую модель Vosk:**

1. Скачайте русскую модель Vosk для Android/малых устройств с официальной страницы моделей: https://alphacephei.com/vosk/models
2. Распакуйте модель.
3. Содержимое модели (папки `am`, `conf`, `graph` и другие файлы модели) поместите в:
   `app/src/main/assets/model/`
4. В результате внутри `model` должны лежать файлы модели, а не ещё одна вложенная папка с названием модели.
5. Пересоберите APK.

Без языковой модели кнопка помощника покажет подсказку, но офлайн-распознавание работать не будет. Модель не включена в этот ZIP, потому что она большая и её размер зависит от выбранного варианта.

## Голос девушки

Приложение произносит приветствие через Android TextToSpeech на русском языке и пытается выбрать женский голос, если установленный TTS-движок предоставляет его. Конкретный тембр зависит от движка и доступных голосовых данных на магнитоле. Если русского голоса нет, нужно установить совместимый пакет русского TTS или подключить отдельный голосовой движок.

## Сборка

1. Распакуйте архив.
2. Откройте папку `BlueDriver-Launcher` в Android Studio через **Файл → Открыть**.
3. Дождитесь синхронизации Gradle и загрузки зависимости Vosk.
4. Добавьте модель по инструкции выше.
5. Выберите **Сборка → Собрать пакет(ы) APK → Собрать APK**.

## Ограничения первой сборки

- Точное приложение радио на TS105 Pro зависит от прошивки. Если оно не находится автоматически, выберите радио в списке приложений; для надёжного запуска потребуется узнать имя пакета радио.
- Обложка и название текущего трека пока являются визуальной карточкой-заготовкой. Для вывода реальных метаданных понадобится подключить конкретный музыкальный плеер через Android MediaSession.
- Женский тембр зависит от установленного TTS-движка и его русских голосовых данных.
- Проект нужно собрать и проверить на реальной магнитоле: здесь не выполнялась сборка APK на устройстве.
